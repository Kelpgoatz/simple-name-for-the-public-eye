# cgrillo typography

These font files are self-hosted Latin subsets from Google Fonts. No visitor-side
request to a font provider is required. Both typefaces use the SIL Open Font
License 1.1; the complete licenses are included beside the font files.

| File | CSS family | Style | Weight range |
| --- | --- | --- | --- |
| `bodoni-moda-latin.woff2` | `Bodoni Moda` | normal | 700–800 |
| `source-serif-4-latin.woff2` | `Source Serif 4` | normal | 400–700 |
| `source-serif-4-italic-latin.woff2` | `Source Serif 4` | italic | 400–700 |

Downloaded 3 November 2026 from the official Google Fonts stylesheets:

- [Bodoni Moda](https://fonts.googleapis.com/css2?family=Bodoni+Moda:wght@700;800&display=swap)
- [Source Serif 4 normal](https://fonts.googleapis.com/css2?family=Source+Serif+4:wght@400..700&display=swap)
- [Source Serif 4 italic](https://fonts.googleapis.com/css2?family=Source+Serif+4:ital,wght@1,400..700&display=swap)
